## 🎯 Project Objective
Upgrade the **Nissh Research System** from a simulated, prompt-only 7-agent loop into a **grounded, evidence-backed startup intelligence platform** drawing architectural best practices from 10 elite open-source research and data repositories:

| # | Repository | Core Role in Upgraded Nissh Architecture |
|---|---|---|
| 1 | **GPT Researcher** | Autonomous multi-query web research, content compression & citation mapping |
| 2 | **DeerFlow** | Long-running agent orchestration, state checkpoints, and subagent memory |
| 3 | **Firecrawl** | Clean DOM scraping, dynamic JS handling, structured web extraction |
| 4 | **Hyperresearch** | Immutable evidence vault, provenance ledger, contradiction & independence detection |
| 5 | **RAGFlow** | Financial reports, government PDF filings, layout-aware table extraction |
| 6 | **PaperQA2** | Academic & technical claim verification, retraction checking, Crossref/OpenAlex |
| 7 | **FinRobot** | Deterministic financial math & valuation execution (Python code vs LLM math) |
| 8 | **OpenBB** | Unified financial/economic data layer & MCP interfaces (RBI, SEBI, SEC EDGAR) |
| 9 | **BettaFish** | Multi-platform social sentiment, customer complaint mining (Reddit, G2, Trustpilot) |
| 10 | **PostHog** | Post-launch product telemetry, session validation, conversion feedback loop |
| * | *Local Deep Research* | Privacy-preserving local LLM research fallback |
